# CodeSnap AI

CodeSnap AI is an AI-powered coding assistant that analyzes code screenshots, explains code, identifies errors, suggests corrections, and helps users generate code through an AI chat interface.

## Features

- Upload and analyze code screenshots
- Explain what the code does
- Detect visible coding errors
- Explain why errors occur
- Generate corrected code
- Suggest code improvements
- Ask coding questions through AI chat
- Save and view chat history
- User login and signup
- Send analysis through email
- Download AI analysis

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- SQLite
- HTML/CSS
- GitHub
